# Bastau — команда сайты

Bastau командасының сайты: қызметтер, жұмыс тәртібі, команда және тіркелу формасы.
Сайт үш тілде: қазақша (әдепкі), орысша, ағылшынша.

## Құрылымы

```
index.html        — бет
css/style.css     — стильдер (дизайн жүйесі файлдың басында)
js/i18n.js        — аудармалар (kk / ru / en)
js/main.js        — тіл ауыстыру, мобильді мәзір, тіркелу формасы
assets/logo.svg   — логотип (векторлық)
assets/favicon.svg
assets/logo-original.png — логотиптің бастапқы суреті
```

Ашу үшін `index.html` файлын браузерде ашсаңыз жеткілікті.

## Бір келкі дизайн (Telegram ботқа да осы)

| Атауы  | Түсі      | Қайда |
|--------|-----------|-------|
| Ink    | `#14121F` | мәтін, логотип діңі, қара фон |
| Violet | `#5B3DF5` | логотиптің жоғарғы бөлігі, негізгі батырмалар |
| Coral  | `#FF5B3A` | логотиптің төменгі бөлігі, екінші батырмалар |
| Paper  | `#F8F8FC` | фон |
| Tint   | `#EFEEF8` | екінші фон |
| Muted  | `#5C5A70` | қосымша мәтін |

Қаріптер: **Unbounded** (тақырыптар), **Golos Text** (мәтін).

## Тіркелу формасы

Қазір форма өтінімді `bastauteam@gmail.com` поштасына дайын хат ретінде ашады.
Telegram бот дайын болғанда, `js/main.js` ішіндегі форма өтінімді тікелей ботқа жіберетін етіп өзгертуге болады.
