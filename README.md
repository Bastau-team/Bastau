# Bastau — сайт

Bastau командасының сайты: не істейміз, қалай жұмыс істейміз, жиі қойылатын сұрақтар, команда және өтінім формасы.
Сайт үш тілде: қазақша (әдепкі), орысша, ағылшынша — жоғарғы оң жақтағы ҚАЗ / РУС / ENG батырмалары.

## Ашу

`index.html` файлын браузерде ашсаңыз жеткілікті. Сервер, жинау (build) керек емес.
GitHub Pages арқылы да жариялауға болады: Settings → Pages → Branch.

## Құрылымы

```
index.html          — бет
css/style.css       — стильдер (түстер мен қаріптер файлдың басында)
js/i18n.js          — аудармалар (kk / ru / en)
js/main.js          — тіл ауыстыру, мобильді мәзір, өтінім формасы
assets/logo.svg     — логотип
assets/favicon.svg  — браузер белгішесі
```

## Мәтінді өзгерту

Барлық мәтін `js/i18n.js` ішінде, үш тілде. Бір мәтінді өзгерткенде үш тілде де өзгертіңіз.

## Өтінім формасы

Форма өтінімді `bastauteam@gmail.com` поштасына дайын хат ретінде ашады (mailto).
Кейін Telegram бот немесе сервер қосылса, `js/main.js` ішіндегі `submit` бөлігін өзгерту жеткілікті.

## Жаңа жұмысты «Жұмыстарымыз» бөліміне қосу

1. `index.html` ішінде `<article class="project">` блогын көшіріп, `<div class="project project--next">` алдына қойыңыз.
2. Ішіндегі `data-i18n` кілттерін жаңасына ауыстырыңыз (мысалы `work.p2.t`, `work.p2.d`).
3. Сол кілттерді `js/i18n.js` ішіне үш тілде (kk, ru, en) жазыңыз.
4. Скриншот болса, оны `assets/work/` папкасына салып, `project__shot` ішіндегі суретті `<img src="assets/work/файл.png" alt="Жоба атауы">` деп ауыстырыңыз.
